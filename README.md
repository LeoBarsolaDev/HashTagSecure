# 🔐 HashTagSecure

A simple yet powerful web app that allows you to generate secure passwords and check the strength of your own.  
Built with **React** and styled using **Tailwind CSS**.

You can try it live [here](https://leobarsoladev.github.io/HashTagSecure/)

---

## ✨ Features

- 🔄 Generate strong and random passwords
- 🔍 Check the strength of any password
- 📱 Responsive design for all screen sizes

---

## 🛠️ Built With

- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)

---
